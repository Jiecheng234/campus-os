# Feature Specification: 设置页功能对接（含 i18n 框架）

**Created**: 2026-10-11
**Status**: Draft
**Input**: User description: "检查并进行设置页功能对接"（经澄清：七项全做；"AI 记忆/操作记录/智能监控"改为**暂不支持**；**完整 i18n** 分**两期**——本轮＝框架 + 设置页，其余页面后续批次；退出登录＝清会话 + 清凭证）

## Overview

让设置页各项"**真正生效并持久化**"：演示模式（写入持久化并**全局即时生效**）、信任此设备（持久化）、语言（**i18n 框架** + 设置页双语化，切换即时生效并持久化）、账号信息展示、退出登录（二次确认 + 清会话与本地凭证）、数据清理（AI 会话 / 学习缓存）、关于与版本（**真实版本号**）。后端尚未实现的"AI 记忆 / 操作记录 / 智能监控"改为**暂不支持**，不再出现误导性文案。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 偏好项持久化与即时生效 (Priority: P1)

用户切换"演示模式"/"信任此设备"后，设置被持久化（重启后保持），且演示模式**立即**影响全应用的真实/演示判定。

**Why this priority**: 当前开关只写内存、不保存，属"假设置"；这是设置页最核心的缺陷，单此一项即完成主要价值。

**Independent Test**: 打开演示模式 → 重启应用 → 演示模式仍为开；且当次运行内校园等页面即按演示模式表现。

**Acceptance Scenarios**:

1. **Given** 设置页，**When** 打开"演示模式"，**Then** 该值被持久化，且当次运行内真实/演示判定立即改变
2. **Given** 已修改偏好，**When** 重启应用，**Then** 偏好保持（演示模式/信任设备/语言）
3. **Given** 写入持久化失败，**When** 发生异常，**Then** 给出可读提示且开关状态不出现"显示已改但实际未保存"的不一致

---

### User Story 2 - i18n 框架与设置页双语 (Priority: P2)

用户在设置页选择"中文 / English"后，**设置页文案立即切换**为该语言并持久化；框架可扩展到其余页面（后续批次迁移）。

**Why this priority**: 语言是当前唯一完全无效果的设置项（值仅本地态），且框架是后续全量翻译的前置。

**Independent Test**: 选择 English 后设置页文案立即变英文；重启后仍为英文；切回中文立即恢复。

**Acceptance Scenarios**:

1. **Given** 设置页，**When** 选择 English，**Then** 设置页全部文案在 1 秒内切换为英文
2. **Given** 已选 English，**When** 重启应用，**Then** 语言仍为 English（持久化）
3. **Given** 尚未迁移的页面，**When** 浏览，**Then** 文案保持中文（框架回退，不出现空白/键名外泄）

---

### User Story 3 - 账号信息展示 (Priority: P3)

设置页展示当前登录账号信息（至少学号；可获得时展示姓名/邮箱）；未登录或演示模式时展示对应状态。

**Why this priority**: 便于确认当前身份；属只读展示。

**Independent Test**: 登录后可见学号（及可获取的姓名/邮箱）；演示模式下显示"演示模式"状态。

**Acceptance Scenarios**:

1. **Given** 已登录，**When** 打开设置页，**Then** 展示账号信息（学号；姓名/邮箱如可获取则一并展示）
2. **Given** 演示模式或未登录，**When** 打开设置页，**Then** 展示对应状态文案，不显示错误占位

---

### User Story 4 - 退出登录（清会话 + 清凭证） (Priority: P4)

用户点击"退出登录"，经二次确认后注销会话并清除本地凭证；之后冷启动不再自动登录。

**Why this priority**: 退出当前无确认且遗留凭证（安全与账号切换诉求）。

**Independent Test**: 退出后回到登录页；冷启动不再自动登录；再次登录需完整输入。

**Acceptance Scenarios**:

1. **Given** 已登录，**When** 点击"退出登录"，**Then** 弹出二次确认；取消则无变化
2. **Given** 确认退出，**When** 执行完成，**Then** 会话注销 + 本地凭证清除，界面回到未登录状态并提示成功
3. **Given** 已退出，**When** 冷启动应用，**Then** 不再自动登录
4. **Given** 退出过程出错，**When** 发生异常，**Then** 给出可读提示（不静默失败）

---

### User Story 5 - 数据清理 (Priority: P5)

用户可清理本地数据（AI 会话与学习缓存），操作前二次确认，完成后给出结果提示。

**Why this priority**: 隐私与故障恢复诉求；仅作用于本地。

**Independent Test**: 清理后对应本地数据为空；界面提示已清理项。

**Acceptance Scenarios**:

1. **Given** 存在本地数据，**When** 触发清理，**Then** 弹出二次确认；取消无变化
2. **Given** 确认清理，**When** 完成，**Then** 对应本地数据被清除并提示结果（清理项列表）

---

### User Story 6 - 关于与版本、"暂不支持"项 (Priority: P6)

设置页展示**真实版本号**与平台信息；"AI 记忆 / 操作记录 / 智能监控"三项明确标注为"暂不支持"。

**Why this priority**: 消除误导（当前"已保存偏好""查看最近操作"暗示已实现）并暴露真实版本。

**Independent Test**: 版本号与应用实际构建一致；三项显示"暂不支持"且点击无跳转。

**Acceptance Scenarios**:

1. **Given** 设置页，**When** 查看版本区，**Then** 展示与当前构建一致的版本号
2. **Given** 三项未实现功能，**When** 查看/点击，**Then** 显示"暂不支持"且不出现"开发中"以外的误导文案

---

### Edge Cases

- 持久化读写失败：给出可读提示；不得造成"开关显示已改但未保存"
- 语言取值异常（非中/英）：回退中文
- 未迁移页面的文案键：回退中文，不显示键名或空白
- 退出登录过程中网络/存储异常：至少完成本地凭证清除或明确提示失败原因
- 数据清理时数据本已为空：给出"已清理/无数据"可读结果，不报错
- 演示模式下点击需登录的设置项（如退出登录）：给出提示，不崩溃
- 版本信息获取失败：回退为可读占位（不崩溃、不显示乱码）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: "演示模式"开关必须**持久化**，并在切换后**当次运行内立即生效**（全应用真实/演示判定随之改变）
- **FR-002**: "信任此设备"开关必须**持久化**（本轮不联动登录/指纹行为；UI 需给出准确语义说明）
- **FR-003**: 必须支持语言选择（中文 / English），并**持久化**
- **FR-004**: 必须提供 **i18n 框架**：统一翻译查找函数 + 中英词典 + 运行时切换能力，新增语言可扩展
- **FR-005**: 语言切换后，**设置页文案必须即时切换**（不重启）；**未迁移页面回退中文**（不出现键名外泄）
- **FR-006**: 必须展示账号信息（学号；姓名/邮箱在**可获取时**展示，不可获取则省略该项）
- **FR-007**: 未登录/演示模式下必须展示对应状态文案（不显示错误占位）
- **FR-008**: "退出登录"必须**二次确认**；确认后**注销会话并清除本地凭证**，界面回到未登录态并提示成功
- **FR-009**: 退出登录出现异常时必须给出可读提示（不静默失败）
- **FR-010**: 必须提供**数据清理**（AI 会话与学习缓存），操作前**二次确认**
- **FR-011**: 数据清理必须**仅作用于本地数据**，完成后提示清理项与结果（无数据亦可读）
- **FR-012**: 必须展示**真实版本号**与应用/平台标识（禁止硬编码版本字符串）
- **FR-013**: "AI 记忆 / 操作记录 / 智能监控"必须标注为**暂不支持**（禁止"已保存偏好""查看最近操作"等误导文案与跳转）
- **FR-014**: 所有设置类写操作失败时必须可读提示，且不得导致设置状态不一致
- **FR-015**: 设置页全部文案必须走 i18n（本轮迁移范围）
- **FR-016**: 偏好默认值必须为：语言=中文、演示模式=关、信任设备=关（与既有默认一致）
- **FR-017**: 布局必须遵循既有 UI 约定（分区标题 + 白卡行组；全宽元素配 `constraintSize` 防右缘溢出）
- **FR-018**: 提示必须使用非弃用 API（`getUIContext().getPromptAction()`）

### Key Entities *(include if feature involves data)*

- **应用设置**：语言、演示模式、信任设备（持久化于设置存储）
- **账号信息**：学号（本地可得）、姓名/邮箱（会话/服务可得时）
- **本地数据项**：AI 会话、学习缓存（可清理）
- **版本信息**：版本号、平台标识
- **翻译词条**：键（key）与中英文案

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 三项偏好修改后**重启仍保持**（100% 保持率）
- **SC-002**: 切换演示模式后，校园等页面在**同一次运行内**立即按演示/真实行为（无需重启）
- **SC-003**: 语言切换后设置页文案在 **1 秒内**完成切换
- **SC-004**: 退出登录后**冷启动不再自动登录**（凭证已清）
- **SC-005**: 数据清理后对应本地数据为空（键不存在或为空）；清理结果 100% 有可读提示
- **SC-006**: 版本号与当前构建版本一致（100% 一致）
- **SC-007**: 三项未实现功能 100% 显示"暂不支持"，页面不存在"已保存偏好/查看最近操作"类误导文案
- **SC-008**: 上述任一操作出现异常时，100% 给出可读中文/英文提示（无崩溃、无静默失败）

## Assumptions

- **i18n 分期**：本轮交付框架 + **设置页**双语化；其余页面按批次后续迁移（未迁移处**回退中文**，不出现空白或键名）
- 账号姓名/邮箱依赖既有会话数据可得性；**仅展示可获取项**（学号取自本地凭证/会话），不可获取时不显示该项
- "信任此设备"本轮**仅持久化**，不联动指纹复用或 2FA 行为（UI 文案需准确表述）
- "AI 记忆 / 操作记录 / 智能监控"的存储/业务后端**本项目未实现**（仅存在存储键占位）→ 本轮不实现，仅改文案
- 演示模式已有全局判定（状态层），本次补齐**持久化**与设置页写入路径
- 版本号来源为**编译期常量或系统包信息**（不得硬编码字符串）
- 退出登录沿用既有会话注销能力，并显式清除本地凭证（安全存储）
- 数据清理沿用既有本地存储键（AI 会话 / 学习缓存），不触达服务端
