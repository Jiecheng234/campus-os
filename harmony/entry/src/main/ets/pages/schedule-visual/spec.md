# Feature Specification: 课表页视觉改进（块状重构）

**Created**: 2026-10-11
**Status**: Draft
**Input**: User description: "推进以下两个特性：课表页视觉效果改进，完整显示课程上课地点等（参照原项目）"（经澄清：**块状课表重构**；**按课程配色**；地点**完整多行展示**；不含当前时间线与点击详情）

## Overview

参照原项目将课表页由"固定单格表格"重构为**块状课表**：课程块按开始/结束节次占据对应行高（可跨多节），**按课程名稳定配色**（同名同色），块内展示**课程名 + 完整上课地点（多行不截断）**；左侧时间轴标示各大节起止时间，日列头展示**星期 + 日期**；既有周导航、加载/空态/错误行为保持不变；演示模式使用同一视觉渲染。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 块状课表与完整课程信息 (Priority: P1)

用户打开课表页，看到课程以**块**呈现：跨节次的课程块高度对应其节次数；块内显示课程名与**完整上课地点**（多行、不截断）；课程配色按课程名稳定生成。

**Why this priority**: 这是本特性核心——当前单格表格既无法表达跨节课程，也把地点截断为一行，信息不可用。

**Independent Test**: 打开课表（真实或演示）即见块状课表；含跨节课程时块高明显大于单节；地点文本完整可见/可读。

**Acceptance Scenarios**:

1. **Given** 已登录且课表数据可用，**When** 打开课表页，**Then** 课程以块状呈现，块高与其节次数一致
2. **Given** 某课程地点较长（≥8 字），**When** 渲染，**Then** 地点完整展示（可折行），不出现单行截断
3. **Given** 同一课程在不同周出现，**When** 切换周次，**Then** 该课程配色保持一致

---

### User Story 2 - 时间轴与日列日期 (Priority: P2)

课表左侧时间轴展示各大节的起止时间；顶部日列头展示"星期 + 日期"，随所选周次变化。

**Why this priority**: 便于对时与跨周辨识；是块状课表的必要刻度参照。

**Independent Test**: 时间轴显示 6 个大节的起止时间；切换周次后日列日期随之更新。

**Acceptance Scenarios**:

1. **Given** 课表已渲染，**When** 查看左侧，**Then** 每个大节显示起止时间
2. **Given** 当前周已显示，**When** 切换上一周/下一周/回本周，**Then** 日列日期（与周范围）同步更新

---

### User Story 3 - 布局稳健与状态一致 (Priority: P3)

长地点、超长课程名、空地点、同时段重叠课程等边界下布局不破版；加载/空态/错误与演示模式行为与既有保持一致。

**Why this priority**: 块状布局引入绝对/跨行定位，需保证边界稳健，避免"视觉改进换来破版"。

**Independent Test**: 构造长地点/空地点/重叠课程场景，界面不溢出、不重叠错乱、不崩溃。

**Acceptance Scenarios**:

1. **Given** 课程地点为空，**When** 渲染，**Then** 不显示地点行且块布局不塌陷
2. **Given** 同一天同一节次存在多门课程，**When** 渲染，**Then** 不重叠错乱（按既定策略堆叠或并列），无崩溃
3. **Given** 课表加载中/为空/失败，**When** 观察，**Then** 既有加载、空态与错误（可重试）行为不变

---

### Edge Cases

- 地点为空或仅空白：不渲染地点行
- 地点/课程名超长：允许折行，超出块高时安全裁剪（不溢出、不遮挡相邻块）
- 课程时间无法映射到大节（异常数据）：跳过该课程并记录日志，不阻塞渲染
- 同一时段多门课程重叠：按既定策略并列/堆叠展示，保证可辨识
- 演示模式：示例课程同样按块状视觉渲染
- 周次切换时数据未返回：保持既有加载态，不出现半渲染错乱

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 课程必须以**块**呈现，块高对应其跨越的节次数（开始节→结束节）
- **FR-002**: 课程配色必须**按课程名稳定生成**（同名同色，跨周一致）
- **FR-003**: 块内必须展示课程名（可多行）与**完整上课地点**（多行、不单行截断）
- **FR-004**: 左侧必须展示时间轴（各大节起止时间）
- **FR-005**: 日列头必须展示"星期 + 日期"，并随所选周次更新
- **FR-006**: 既有周导航（上一周/下一周/回本周）与加载/空态/错误（可重试）行为必须保持不变
- **FR-007**: 演示模式必须使用同一块状视觉渲染示例课程
- **FR-008**: 布局必须稳健：无横向溢出、无相邻块遮挡；长文本安全裁剪
- **FR-009**: 课表页用户可见文案必须纳入 i18n 词典（与 `i18n-migration` 首批范围一致）
- **FR-010**: 渲染性能必须满足单周课表流畅呈现（无明显卡顿；块数为常规量级）

### Key Entities *(include if feature involves data)*

- **课程事件**：标识、日期、课程名、上课地点、开始时间、结束时间（既有数据模型，本特性不改）
- **大节**：序号、起止时间（用于时间轴与块高换算）
- **课程配色**：由课程名稳定映射得到的颜色

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 打开课表页，3 秒内呈现块状课表（真实与演示模式均满足）
- **SC-002**: 同名课程配色跨周一致（一致率 100%）
- **SC-003**: 长度 ≥ 8 字的地点**不再被单行截断**（完整可读）
- **SC-004**: 跨 2 节的课程块高约为单节块的 2 倍（误差 ±10%）
- **SC-005**: 既有交互回归通过（周导航/回本周/加载/空态/错误）行为无变化
- **SC-006**: 无布局溢出（无横向滚动、左右不裁切；重叠课程可辨识）

## Assumptions

- **不含**当前时间指示线与点击课程查看详情（用户已明确选择范围）
- 大节定义沿用既有 6 大节（08:00 / 09:50 / 13:30 / 15:20 / 17:05 / 19:20 起）
- 数据源不变（既有课表事件已含地点字段）；本特性**不新增数据请求**
- 课程配色在客户端生成（无服务端配色数据）
- 课表页文案随 `i18n-migration` 首批一并迁移（两个特性协同，互不阻塞）

## Open Questions

- 同一时段重叠课程的呈现策略（并列分栏 vs 顺序堆叠）
- 是否需要在块内显示"起止时间"文本（当前仅课程名 + 地点）
- 深色/浅色主题下的配色对比度是否需单独校准
