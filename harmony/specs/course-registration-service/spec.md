# Feature Specification: 选课系统服务（CourseRegService）

**Created**: 2026-10-19  
**Status**: Draft  
**Input**: 用户描述：新建选课系统服务，覆盖学期、已选课程、课余量搜索、选课、退课；范围含 WebVPN/GBK/表单 token、SessionManager 单例、错误归一、日志脱敏；非目标为 AI 工具注册（T14）与页面 UI。

## Overview

为 CampusOS 鸿蒙端提供选课系统的数据服务，覆盖学期列表、已选课程、课余量搜索、选课与退课。该服务是后续 AI 选课工具（T14）与选课页面的唯一数据入口；本轮只交付服务能力，不提供页面 UI，也不注册 AI 工具。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查询可选学期 (Priority: P1)

作为已登录学生，我希望获取选课系统提供的学期列表，以便选择要查看或操作的学期。

**Why this priority**: 学期是已选课程、课余量搜索、选课与退课的必需输入；没有学期列表，其余能力无法开始。

**Independent Test**: 在真实登录态下请求学期列表，能返回至少一个“学期 ID + 名称”；未登录时返回明确的结构化错误而不是空成功。

**Acceptance Scenarios**:

1. **Given** 已登录且 WebVPN 会话可用，**When** 请求学期列表，**Then** 返回学期集合，每项包含形如 `2024-2025-2` 的 ID 与非空名称。
2. **Given** 未登录或登录态已失效，**When** 请求学期列表，**Then** 返回“需要登录/会话已失效”的结构化错误，调用方可据此提示用户重新登录。

---

### User Story 2 - 查看已选课程 (Priority: P1)

作为已登录学生，我希望查看指定学期已选课程，以便确认选课结果与课程信息。

**Why this priority**: “已选课程”是选课/退课的前置信息，也是 T14 只读工具的核心数据。

**Independent Test**: 在真实登录态下指定学期请求已选课程，返回课程类型、志愿、课程号、课序号、名称、时间、教师、学分、是否二级选课等字段；无已选课程时返回空列表而不是错误。

**Acceptance Scenarios**:

1. **Given** 已登录且学期有效，**When** 请求已选课程，**Then** 每条记录包含类型、志愿、课程号、课序号、名称、时间、教师、学分与二级选课标记。
2. **Given** 该学期没有已选课程，**When** 请求已选课程，**Then** 返回空列表并标记成功。
3. **Given** 会话已过期，**When** 请求已选课程，**Then** 自动尝试恢复一次；恢复仍失败时返回结构化错误，不返回空列表冒充成功。

---

### User Story 3 - 课余量搜索 (Priority: P1)

作为已登录学生，我希望按学期、课程号、课程名、星期与节次搜索课余量，以便判断是否值得选课。

**Why this priority**: 课余量搜索是选课决策的核心只读能力，也是 T14 选课前预览的数据来源。

**Independent Test**: 在真实登录态下按学期搜索，返回当前页、总页数、总条数与课程余量列表；按课程号可缩小结果；无结果时返回空列表与分页信息。

**Acceptance Scenarios**:

1. **Given** 已登录且学期有效，**When** 仅按学期搜索，**Then** 返回课程余量列表及“当前页/总页数/总条数”。
2. **Given** 已登录且学期有效，**When** 按课程号或课程名搜索，**Then** 只返回匹配课程；无匹配时返回空列表且分页字段可读。
3. **Given** 指定页码超出总页数，**When** 搜索，**Then** 返回服务端实际页码/空列表，不伪造数据。
4. **Given** 搜索结果行缺少必要列，**When** 解析，**Then** 跳过该行并记录可诊断的非敏感日志，不影响其余结果。

---

### User Story 4 - 选课 (Priority: P2)

作为已登录学生，我希望在选课开放时段提交选课，以便把课程加入已选列表。

**Why this priority**: 写操作依赖只读能力与表单令牌校验；风险高于查询，必须建立在稳定的学期与搜索能力之上。

**Independent Test**: 在选课开放时段，用真实账号对一门可安全退选的课程执行选课，服务返回服务端明确结果；关闭时段返回“未开放/服务端拒绝”的可读错误。

**Acceptance Scenarios**:

1. **Given** 已登录、学期有效且选课开放，**When** 提交受支持的选课类型、课程号、课序号与志愿，**Then** 返回服务端结果消息，且只有明确成功消息才标记成功。
2. **Given** 选课类型不在支持范围（仅 `bx`/`xx`/`rx`/`ty`），**When** 提交，**Then** 返回“不支持的选课类型”结构化错误，不发起网络请求。
3. **Given** 课程已满、重复选课或不在开放时段，**When** 提交，**Then** 原样返回服务端可读拒绝原因，并标记为业务拒绝而非系统故障。
4. **Given** 选课表单缺少令牌，**When** 提交，**Then** 返回“表单令牌缺失/会话异常”结构化错误，不重试写操作。

---

### User Story 5 - 退课 (Priority: P2)

作为已登录学生，我希望在允许退课的时段删除已选课程，以便调整课表。

**Why this priority**: 退课与选课共用表单令牌与会话恢复链路，但属于不可逆写操作，必须单独确认与验证。

**Independent Test**: 在允许退课时段，对一门受控课程执行退课并回查已选列表确认删除；非开放时段返回服务端可读拒绝原因。

**Acceptance Scenarios**:

1. **Given** 已登录、学期有效且退课开放，**When** 提交学期、课程号与课序号，**Then** 返回服务端结果消息，且只有明确成功消息才标记成功。
2. **Given** 课程不在已选列表或退课未开放，**When** 提交，**Then** 原样返回服务端可读拒绝原因。
3. **Given** 会话在提交前失效，**When** 提交，**Then** 先尝试一次会话恢复；恢复失败则返回结构化错误，绝不伪造退课成功。

---

### Edge Cases

- 会话过期后访问选课页面被重定向到 WebVPN/ID 登录页：必须识别为“会话失效”，不得把登录页当作数据解析。
- 选课/退课不在开放时段：必须原样保留服务端可读提示，不能统一成“系统错误”。
- 课程已满、志愿受限、重复选课、课序号不存在：必须归类为业务拒绝并保留服务端消息。
- 搜索无结果、页码越界、表格列缺失：返回空列表或跳过坏行，不抛出不可读异常。
- 服务端返回非预期 HTML、缺少结果消息或缺少表单令牌：返回“响应解析失败/会话异常”结构化错误。
- 同一课程被重复提交：服务端拒绝时如实返回；服务端接受时以服务端结果为准，不自行去重。
- 未登录、凭证缺失、自动恢复失败：返回“需要登录”错误，调用方负责引导登录。
- 日志与错误详情中不得出现表单 token、Cookie、学号、密码等敏感明文。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 服务 MUST 复用现有已登录会话访问选课系统，不得要求用户再次输入密码或单独建立登录链路。
- **FR-002**: 服务 MUST 能获取选课系统提供的学期列表，返回学期 ID 与名称。
- **FR-003**: 服务 MUST 能按学期获取已选课程，返回类型、志愿、课程号、课序号、名称、时间、教师、学分与二级选课标记。
- **FR-004**: 服务 MUST 能按学期执行课余量搜索，并支持可选的课程号、课程名、星期、节次与页码条件。
- **FR-005**: 搜索结果 MUST 包含当前页、总页数、总条数与课程余量列表；列表项包含课程号、课序号、名称、容量、余量、排队人数、教师与时间。
- **FR-006**: 选课 MUST 支持 `bx`（必修）、`xx`（限选）、`rx`（任选）、`ty`（体育）四种类型；其余类型 MUST 返回“不支持的选课类型”。
- **FR-007**: 选课 MUST 支持第一、第二、第三志愿；非法志愿 MUST 在发起请求前被拒绝。
- **FR-008**: 选课 MUST 在提交前获取并校验服务端表单令牌；令牌缺失时 MUST 返回结构化错误且不得提交写请求。
- **FR-009**: 退课 MUST 支持按学期、课程号、课序号删除已选课程，并同样校验表单令牌。
- **FR-010**: 选课与退课 MUST 原样返回服务端结果消息；只有服务端明确成功时才标记成功，禁止本地推断成功。
- **FR-011**: 所有失败 MUST 归一为稳定错误码、可本地化文案键与“是否可重试”标志，至少覆盖：未登录、会话过期、网络/HTTP 失败、响应解析失败、业务拒绝、不支持的类型/参数、服务端异常。
- **FR-012**: 错误对象与错误详情 MUST NOT 包含表单 token、Cookie、学号、密码等敏感明文。
- **FR-013**: 日志 MUST NOT 记录表单 token、Cookie、学号、密码或完整表单体；允许记录阶段、课程号、课序号、页码、耗时、结果码与脱敏后的长度信息。
- **FR-014**: 会话失效时，服务 MUST 先尝试默认漫游恢复；默认漫游仍落回登录页时，MUST 回退到信息门户漫游一次；全部失败后返回“需要登录/会话失效”结构化错误。
- **FR-015**: 服务 MUST 在进程内缓存“会话已激活”状态以减少重复漫游，并在登录/退出复位时清除该状态。
- **FR-016**: 服务 MUST 通过统一单例入口暴露，并与现有校园服务采用一致的构造与复位约定。
- **FR-017**: 服务 MUST 对选课系统返回的 GBK 响应做正确解码（复用现有传输层的编码判定），不得出现乱码字段。
- **FR-018**: 服务 MUST NOT 直接依赖页面 UI 或 AI 工具；页面与 T14 只通过该服务读取/写入选课数据。
- **FR-019**: 只读接口 MUST 在服务端返回空结果时区分“成功但为空”与“失败”，不得用空列表掩盖错误。
- **FR-020**: 写操作 MUST 在调用前校验参数完整性（学期、课程号、课序号、类型、志愿），不完整时直接返回参数错误，不发起网络请求。

### Key Entities *(include if feature involves data)*

- **学期（Semester）**：选课系统提供的学期标识与显示名称；ID 形如 `2024-2025-2`，是其余接口的必需输入。
- **已选课程（SelectedCourse）**：某学期已选中的课程记录，包含类型、志愿、课程号、课序号、名称、时间、教师、学分与二级选课标记。
- **课余量课程（RemainingCourse）**：搜索结果中的课程记录，包含课程号、课序号、名称、容量、余量、排队人数、教师与时间。
- **搜索结果（RemainingSearchResult）**：一次分页搜索的完整结果，包含当前页、总页数、总条数与课程列表。
- **服务错误（CourseRegError）**：统一失败描述，包含稳定错误码、可本地化文案键、是否可重试，以及不含敏感信息的可选详情。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 真实登录态、正常网络下，学期列表、已选课程、课余量搜索三类只读请求均能在 10 秒内返回可解析结果。
- **SC-002**: 对服务端返回的完整表格行，学期/已选课程/搜索结果的字段解析完整率为 100%；缺列行被跳过且不影响其余行。
- **SC-003**: 所有失败路径都能返回稳定错误码与可本地化文案键，调用方无需解析中文字符串或英文异常。
- **SC-004**: 对日志与错误对象抽样检查，包含表单 token、Cookie、学号或密码明文的记录为 0 条。
- **SC-005**: 选课/退课的服务实现与参数校验完成；由于当前不在选课开放时段，本轮不进行真实增删测试，开放时段按受控步骤（指定可安全退选的课程）可完成验证。
- **SC-006**: 本轮交付通过 ArkTS 静态检查与构建，不引入新的构建错误。

## Assumptions

- 复用现有 `SessionManager` / `TsinghuaAuthService` 的登录态与 Cookie 池，不新增登录流程。
- WebVPN 通道、Cookie 同步与 GBK 解码由现有传输层负责；选课系统的 WebVPN token 已纳入 GBK 判定。
- 学期列表来自选课系统页面，不额外推断“当前学期”；调用方选择学期。
- 选课类型仅承诺 `bx`/`xx`/`rx`/`ty`；RN 类型声明中的其余值不作承诺。
- 选课志愿仅承诺 1/2/3；非法值在本地拒绝。
- 选课/退课是否开放由服务端决定；服务端拒绝时保留其可读消息，不在客户端绕过限制。
- 本轮不提供页面 UI、不注册 AI 工具；这些由后续任务消费本服务。
- 当前非选课开放时段，选课/退课只做实现与静态验证，真实增删测试推迟到开放时段或独立验证会话。

## Open Questions

- 无阻塞问题。已确认：会话激活采用“默认漫游失败后回退信息门户漫游”；选课类型为 `bx`/`xx`/`rx`/`ty`；错误采用“结构化错误码 + 可本地化文案键”；选课/退课的真实增删测试因当前非开放时段而推迟。
