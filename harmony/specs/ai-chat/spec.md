# Feature Specification: AI 真实对话（流式，多 provider）

**Created**: 2026-10-13
**Status**: Draft
**Input**: User description: "进行AI页面相关内容的实现"（经澄清：**真实 LLM 对话**——预设/自定义 provider + API Key + **流式输出** + 多会话持久化；**不含**工具调用/Agent；配置入口在**设置页**；API Key 存**系统关键资产存储**）

## Overview

把 AI 页从"本地 mock 应答"升级为**真实大模型对话**：支持多个 OpenAI 兼容 provider（预设 + 自定义 baseUrl/model）、**API Key 在设置页配置并存入系统关键资产存储（ASSET）**、**流式输出**（增量渲染、可中断）、**多会话持久化**（新建/切换/删除，重启恢复）。未配置或演示模式时给出引导/使用本地示例且**不发起网络请求**。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 配置模型与密钥 (Priority: P1)

用户在设置页"AI 模型"区选择预设 provider（或填写自定义 baseUrl/model），并输入 API Key 保存；配置持久化且冷启动仍生效，API Key **不落明文到偏好设置**。

**Why this priority**: 无配置则整条链路不可用；是本特性的前置。

**Independent Test**: 保存配置后重启应用，provider 与 Key 仍生效；检查偏好设置中无 Key 明文。

**Acceptance Scenarios**:

1. **Given** 设置页，**When** 选择预设并输入 API Key 后保存，**Then** 配置持久化，页面显示已配置状态
2. **Given** 已保存配置，**When** 冷启动应用，**Then** provider 与 Key 仍可用（无需重新输入）
3. **Given** 偏好设置存储，**When** 检查，**Then** **不存在** API Key 明文（仅存在于安全存储）
4. **Given** 用户清除配置，**When** 保存，**Then** Key 与 provider 配置被清除且 AI 页回到未配置引导

---

### User Story 2 - 流式对话 (Priority: P2)

用户在 AI 页输入并发送消息，回复**逐步（流式）**显示；可**中断**生成；失败时给出可读提示且不丢失已输入/已生成内容。

**Why this priority**: 对话是 AI 页的核心用途；流式显著改善体验。

**Independent Test**: 发送一条消息即可看到增量回复；点"停止"后追加立即停止且内容保留。

**Acceptance Scenarios**:

1. **Given** 已配置且联网，**When** 发送消息，**Then** 回复以增量方式逐步显示，结束后收敛为完整回复
2. **Given** 正在流式输出，**When** 点击"停止"，**Then** 停止追加、保留已生成内容，并可继续发送新消息
3. **Given** 网络/鉴权/限流失败，**When** 发生错误，**Then** 显示可读中文（可英）提示，且用户输入不丢失
4. **Given** 流式进行中，**When** 离开页面，**Then** 请求被终止，不产生后台悬挂

---

### User Story 3 - 多会话持久化 (Priority: P3)

用户可新建、切换、删除会话；会话与消息在本地持久化，重启后恢复。

**Why this priority**: 便于按主题分开展开对话；为长期使用的基础。

**Independent Test**: 新建两个会话各自对话，重启后两会话及消息均可恢复。

**Acceptance Scenarios**:

1. **Given** AI 页，**When** 新建会话，**Then** 出现空会话并可独立对话
2. **Given** 存在多个会话，**When** 切换，**Then** 显示该会话历史消息
3. **Given** 某会话，**When** 删除（需确认），**Then** 该会话从列表移除
4. **Given** 已有会话与消息，**When** 重启应用，**Then** 会话与消息恢复

---

### User Story 4 - 未配置/演示模式降级 (Priority: P4)

未配置 API Key 时给出清晰引导（前往设置配置）且**不发起请求**；演示模式使用本地示例应答且**零网络请求**。

**Why this priority**: 避免"发了没反应/报错难懂"的困惑；保证演示模式不触网。

**Independent Test**: 未配置时发送消息应看到引导文案且无网络请求；演示模式下回复来自本地示例。

**Acceptance Scenarios**:

1. **Given** 未配置 Key，**When** 尝试发送，**Then** 展示"请先在设置中配置"引导（可一键跳转），**不发起请求**
2. **Given** 演示模式，**When** 发送消息，**Then** 回复来自本地示例，**零网络请求**
3. **Given** 已配置但离线，**When** 发送，**Then** 提示网络不可用并保留输入

---

### Edge Cases

- API Key 错误/失效（401）：提示"密钥无效或已过期"，引导重新配置；不清除用户其它设置
- 限流（429）/服务端 5xx：可读提示 + 可重试；输入与历史不丢
- 流中断（网络断开/超时）：保留已生成内容并标注"生成中断"
- 极长回复：可滚动、长词换行不溢出；输入框在键盘弹出时仍可用
- 会话过多/消息过多：列表与消息渲染不卡顿（分页或上限策略）
- 自定义 baseUrl 非法（缺协议/空）：保存时校验并给出可读提示
- 日志中不得出现 API Key 或请求鉴权头

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 设置页必须提供"AI 模型"配置区：预设选择、自定义 baseUrl 与 model、API Key 输入（掩码显示）与保存/清除
- **FR-002**: API Key 必须保存在**系统关键资产存储**，**禁止**写入偏好设置明文
- **FR-003**: provider 配置（预设标识 / 自定义 baseUrl / model）必须持久化（既有设置存储）
- **FR-004**: 请求必须遵循 OpenAI 兼容协议（`/chat/completions`，Bearer 鉴权，`stream` 开启）
- **FR-005**: 必须**流式**渲染助手回复（增量追加，正确收尾）
- **FR-006**: 必须支持**中断**生成（停止），中断后保留已生成内容
- **FR-007**: 必须支持多会话（新建/切换/删除），会话与消息**本地持久化**并在重启后恢复
- **FR-008**: 未配置 API Key 时必须给出可读引导且**不发起请求**（可跳转设置页）
- **FR-009**: 演示模式必须使用本地示例应答且**零网络请求**
- **FR-010**: 错误（网络/401/429/5xx/超时）必须转为可读提示，且**不丢失**用户输入与已有内容
- **FR-011**: AI 页与新增设置区文案必须走 i18n（`ai.*` / `settings.*` 扩展），中英切换一致
- **FR-012**: 布局必须稳健：长回复滚动、长文本换行不溢出、键盘弹出时输入可用
- **FR-013**: 请求必须可取消（离开页面/中断/超时），不得残留悬挂请求
- **FR-014**: 必须复用既有会话存储契约与状态管理器（不破坏既有 API），增量实现
- **FR-015**: 日志与错误信息中不得输出 API Key 或鉴权头

### Key Entities *(include if feature involves data)*

- **AI Provider 配置**：预设标识、baseUrl、model（自定义时）
- **API Key**：存于安全存储，仅用于请求头
- **会话**：标识、标题、创建/更新时间、消息列表
- **消息**：角色（用户/助手）、内容、时间、状态（正常/生成中/中断/失败）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 配置保存后**冷启动仍生效**（provider 保持、Key 可读）
- **SC-002**: 网络正常时**首段回复 ≤3 秒**出现，且为增量显示
- **SC-003**: 中断后 ≤1 秒停止追加且已生成内容保留
- **SC-004**: 重启后**会话与消息可恢复**（含多会话）
- **SC-005**: 未配置场景下**请求发起次数 = 0**，且给出可读引导
- **SC-006**: 演示模式**网络请求 = 0**
- **SC-007**: 各类错误 100% 展示可读提示（无崩溃、无原始报文/密钥外泄）
- **SC-008**: 偏好设置中 API Key 明文**出现次数 = 0**

## Assumptions

- 仅支持 **OpenAI 兼容**协议（`/chat/completions` + SSE 流），不接入非兼容 SDK/私有协议
- **不含工具调用/Agent 能力**（本轮范围外，后续批次；既有 `AIAgentTypes` 仅作保留）
- API Key 存 **ASSET**（复用凭证安全存储能力）；provider 配置存既有设置存储
- 流式解析在 ArkTS 侧实现；**若当前网络封装不支持流式读取**，则加法式扩展之，必要时可降级为非流式并在报告中说明
- 会话数据沿用既有本地存储键（`AI_CONVERSATIONS`）与其管理能力
- 文案走既有 i18n 框架（`ai.*` / `settings.*` 扩展；未迁移页面不受影响）
- 演示模式语义与既有约定一致（不触网、示例数据）
