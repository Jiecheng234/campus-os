# Feature Specification: 课表交互增强（时间指示线 / 课程详情 / 扩展色板）

**Created**: 2026-10-18
**Status**: Draft
**Input**: User description: "实现课表功能拓展： 课表：当前时间指示线 / 点击课程看详情 / 扩大色板（避免"同色不同课"）"

## Overview

在既有块状课表（`specs/schedule-visual`）之上补充三项交互与可读性能力：查看本周时在**今天所在日列**绘制随真实时间移动的**当前时间指示线**；**点击任意课程块**以底部弹层查看课程详情；把课程配色从 8 组**扩展到 16 组**，并以「课名散列基址 + 本周内冲突顺延」保证本周不同课程名不撞色。本特性不新增网络请求、不改变教务数据源与既有周导航行为。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 点击课程查看详情 (Priority: P1)

用户在某天的课程块上点击，页面底部弹出该课程的详情：课程名、上课地点、日期、星期、节次区间、起止时间；点击关闭后回到课表原状态。

**Why this priority**: 课程块受尺寸限制只能显示课程名与地点，时间、节次等关键信息无法看到；点击详情是把课表从"能看"变成"能用"的最低成本能力。

**Independent Test**: 在真实或演示课表中点击任意课程块，弹层出现且六项信息与块数据一致；关闭后周次与滚动位置不变。

**Acceptance Scenarios**:

1. **Given** 课表已渲染，**When** 点击任一课程块，**Then** 底部弹层展示课程名、地点、日期、星期、节次区间、起止时间
2. **Given** 某课程地点为空，**When** 打开其详情，**Then** 地点一栏显示明确的"未填写"占位文案，不出现空白或占位符原文
3. **Given** 详情弹层已打开，**When** 关闭弹层，**Then** 返回课表且当前周次、滚动位置、课程块配色均不变化

---

### User Story 2 - 当前时间指示线 (Priority: P2)

用户查看**本周**课表时，今天所在日列出现一条横向指示线，标出此刻处于当天课表的哪个位置；指示线每分钟随真实时间移动。

**Why this priority**: 解决"现在上到哪节课"的即时判断问题，是课表的高频使用场景；但依赖时间计算与今日列定位，放在详情之后。

**Independent Test**: 在本周视图下观察今天列出现指示线；切换到上一周/下一周后指示线消失；等待或修改系统时间后位置更新。

**Acceptance Scenarios**:

1. **Given** 当前为本周且今天在可见日期范围内，**When** 打开课表，**Then** 今天所在日列出现横向指示线，位置与当前时刻对应
2. **Given** 当前查看上一周或下一周，**When** 观察课表，**Then** 指示线不出现
3. **Given** 指示线已显示，**When** 真实时间前进 1 分钟，**Then** 指示线位置按节次刻度同步更新，无需手动刷新
4. **Given** 当前时间早于当天第一节开始或晚于最后一节结束，**When** 查看课表，**Then** 指示线隐藏且无布局异常

---

### User Story 3 - 扩展色板，避免同色不同课 (Priority: P3)

课程配色从 8 组扩展到 16 组；同一周内不同课程名不得共用同一颜色（本周不同课程名 ≤ 16 时），同名课程保持同色。

**Why this priority**: 直接影响课程辨识效率，但属于视觉优化；实现独立、风险最低，可在前两项之后完成。

**Independent Test**: 使用演示课表（8 门不同课程）或构造 16 门不同课程的周课表，统计本周不同课程名共用颜色的对数应为 0。

**Acceptance Scenarios**:

1. **Given** 一周内有 8 门不同课程，**When** 渲染课表，**Then** 8 门课程颜色两两不同
2. **Given** 一周内有 16 门不同课程，**When** 渲染课表，**Then** 16 门课程颜色两两不同
3. **Given** 同一课程在同一周出现多次，**When** 渲染课表，**Then** 各次出现颜色一致
4. **Given** 某课程未发生配色冲突，**When** 切换到其它周查看，**Then** 该课程颜色保持不变

---

### Edge Cases

- 今天列存在跨节课程或同时段并列课程时，指示线仍须清晰可见且不遮挡课程名
- 当前时间处于两个大节之间的课间间隔（如 09:35–09:50）时，指示线吸附到相邻节边界，不落在空白处
- 系统时间早于 08:00 或晚于 21:45 时，指示线隐藏，课表其余部分正常渲染
- 课程地点为空或仅空白字符时，详情弹层显示"未填写"占位
- 课程名超长时，详情弹层完整展示，不做单行截断
- 弹层打开期间切换系统语言，弹层内文案随之刷新
- 本周不同课程名超过 16 个时，允许复用颜色，但前 16 个不同课名必须颜色唯一
- 演示模式与真实数据使用同一套指示线、详情与配色逻辑

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 用户点击任意课程块时，系统 MUST 弹出课程详情弹层，展示课程名、地点、日期、星期、节次区间、起止时间六项信息
- **FR-002**: 课程地点为空或仅空白时，详情弹层 MUST 显示 i18n 化的"未填写"占位，不得出现空白、`undefined` 或键名原文
- **FR-003**: 详情弹层 MUST 支持显式关闭（关闭按钮 / 点击遮罩 / 返回键）；下滑关闭 MUST 被禁用，避免与内容区滚动冲突；关闭后 MUST 保持当前周次、滚动位置与课程配色不变
- **FR-004**: 仅当用户查看**本周**且今天位于可见日期范围内时，系统 MUST 在今天所在日列绘制横向当前时间指示线；查看其它周时 MUST 不绘制
- **FR-005**: 指示线的纵向位置 MUST 按当前时刻映射到 6 大节刻度（节内按时间比例插值），与真实时间的对应误差 MUST ≤ 5 分钟
- **FR-006**: 指示线 MUST 至少每 60 秒自动刷新一次位置，且页面重新可见时 MUST 立即重算
- **FR-007**: 当前时刻处于课间间隔时，指示线 MUST 吸附到相邻节边界；早于 08:00 或晚于 21:45 时 MUST 隐藏
- **FR-008**: 课程调色板 MUST 扩展为 16 组，每组保持背景色 / 文字色 / 边框色三色结构，文字与背景对比度 MUST 不低于现有 8 组的最低值
- **FR-009**: 课程颜色分配 MUST 以课程名散列为基址；同一周内若基址已被其它课程名占用，MUST 按固定规则顺延到下一个空闲颜色
- **FR-010**: 当本周不同课程名数量 ≤ 16 时，任意两门不同课程名 MUST NOT 共用同一颜色；同名课程 MUST 同色
- **FR-011**: 未发生配色冲突的课程 MUST 在跨周切换时保持颜色不变
- **FR-012**: 本特性 MUST NOT 新增任何网络请求；详情所需字段 MUST 全部来自已加载的当周课表数据
- **FR-013**: 本特性新增的全部用户可见文案 MUST 纳入 i18n 词典（`schedule.*` 前缀，中文 / 英文双语）
- **FR-014**: 既有周导航、加载态、空态、错误可重试、演示模式行为 MUST 保持不变

### Key Entities *(include if feature involves data)*

- **课程块**：课表渲染单元，包含星期索引、起止节次、课程名、地点、日期、起止时间与配色索引
- **配色条目**：一组浅色主题下的背景色 / 文字色 / 边框色，调色板共 16 组
- **时间指示**：今天所在日列索引、当前时刻在 6 大节刻度上的纵向位置与可见状态
- **课程详情**：由被点击课程块派生的展示数据，不引入新的持久化实体

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 点击任意课程块后 300ms 内出现详情弹层，六项信息与课程块数据一致率 100%
- **SC-002**: 本周视图下，指示线 100% 出现在今天所在日列；切换到上/下周后出现次数为 0
- **SC-003**: 指示线位置与真实时刻的误差 ≤ 5 分钟（按节次刻度换算），连续观察 10 分钟无漂移
- **SC-004**: 演示课表 8 门不同课程的撞色对数为 0（现状为 2 对）
- **SC-005**: 构造 16 门不同课程名的周课表，撞色对数为 0
- **SC-006**: 既有交互回归（周导航 / 回本周 / 加载 / 空态 / 错误 / 演示模式）失败数为 0

## Assumptions

- 大节刻度沿用既有 6 大节：08:00–09:35、09:50–12:15、13:30–15:05、15:20–16:55、17:05–18:40、19:20–21:45
- 「本周」判定沿用页面既有语义：周偏移为 0 即本周，此时今天必然在可见 7 天内
- 课间间隔的指示线吸附到相邻节边界（视觉上与上一节末尾/下一节开头重合）
- 详情弹层采用底部弹层形态，固定高度约 360vp、内容区可滚动，不新增独立页面路由
- 详情弹层禁用下滑关闭（`SLIDE_DOWN`），保留关闭按钮 / 点击遮罩 / 返回键关闭
- 不展示教师与开课周次：现有教务事件只提供日期、课程名、地点、起止时间，本特性不扩展数据源
- 配色在客户端生成；本周不同课程名超过 16 个时按固定规则复用颜色
- 加深色主题不在本特性范围，沿用现有浅色主题配色
- 既有 `specs/schedule-visual` 明确排除的两项能力由本特性补齐，两者互不冲突
