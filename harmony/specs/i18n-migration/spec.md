# Feature Specification: i18n 后续迁移（核心骨架 + 高频页）

**Created**: 2026-10-11
**Status**: Draft
**Input**: User description: "推进 i18n 后续"（经澄清：首批迁移 **核心骨架 + 高频页**——底部导航 + 首页/学习/课表/校园/AI/登录 及其状态与错误文案）

## Overview

在既有 i18n 框架（`utils/I18n.ets`：词典 + `t()` + AppStorage `locale`）之上，把**核心骨架与高频页面**的用户可见文案从硬编码中文迁移到词典，实现**语言切换后这些页面即时双语**；未迁移页面保持中文且**不泄露键名/空白**。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 底部导航与页面标题双语 (Priority: P1)

用户切换语言后，底部导航（首页/学习/课表/校园/AI/设置）与各页标题/副标题立即切换。

**Why this priority**: 骨架文案是全局可见度最高的部分，单此一项即让"双语"可感。

**Independent Test**: 切到 English 后底部导航与各页标题均为英文；切回中文即时恢复。

**Acceptance Scenarios**:

1. **Given** 已切到 English，**When** 浏览底部导航与各页头部，**Then** 文案为英文
2. **Given** 语言切换，**When** 停留在任一骨架页面，**Then** 文案**即时**切换（无需重启）

---

### User Story 2 - 高频页文案双语 (Priority: P2)

首页/学习/课表/校园/AI/登录 六个高频页面的用户可见文案（区块标题、按钮、行标签、占位提示等）迁移为词典键并随语言切换。

**Why this priority**: 覆盖日常使用主路径；范围可控且收益最直接。

**Independent Test**: 逐页切到 English，页面内**无残留中文**（业务数据除外）。

**Acceptance Scenarios**:

1. **Given** English，**When** 打开任一高频页，**Then** 静态文案为英文（数据内容除外）
2. **Given** 中文，**When** 打开同一页面，**Then** 文案为中文（回退正常）

---

### User Story 3 - 状态与错误文案双语 (Priority: P3)

加载中、空态、失败、重试、演示模式提示等状态类文案纳入词典并随语言切换。

**Independent Test**: 在 English 下触发加载/空态/错误（或演示模式），提示均为英文。

**Acceptance Scenarios**:

1. **Given** English，**When** 页面加载中/为空/请求失败，**Then** 状态与提示文案为英文
2. **Given** English，**When** 处于演示模式，**Then** 演示提示文案为英文

---

### User Story 4 - 未迁移范围回退（不泄露键名） (Priority: P4)

尚未迁移的页面（校园子页、学习子页等）在 English 下仍展示中文，且**不出现键名、空白或占位符外泄**。

**Independent Test**: English 下进入未迁移子页，文案为中文且无 `xxx.yyy` 形态键名或空白。

**Acceptance Scenarios**:

1. **Given** English，**When** 进入未迁移子页，**Then** 文案为中文，无键名/空白外泄
2. **Given** 词典缺项，**When** 命中该键，**Then** 回退中文（仍缺则显示可读占位）

---

### Edge Cases

- 词典缺少某键：回退中文；中文亦缺显示可读占位（禁止空白/键名）
- 含变量的文案（如"共 N 封""第 X 周"）：需安全替换，不暴露原始键或占位符
- 业务数据中的中文（课程名、邮件主题、机构名等）：**不翻译**，保持原样
- 语言为非法值：回退中文（框架既有行为）
- 页面在语言切换时正在加载：加载完成后文案应已是目标语言

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 词典必须按**页面前缀**扩展（如 `nav.*` / `home.*` / `learning.*` / `schedule.*` / `campus.*` / `ai.*` / `login.*` / `status.*`）
- **FR-002**: 首批范围内页面的**用户可见静态文案**必须改走 `t()`（不残留硬编码中文）
- **FR-003**: 底部导航标题必须随语言切换即时更新
- **FR-004**: 页面标题/副标题（头部组件传入的文案）必须随语言切换即时更新
- **FR-005**: 状态类文案（加载中 / 空态 / 失败 / 重试 / 演示提示）必须纳入词典
- **FR-006**: 首批页面必须订阅语言状态（`@StorageLink('locale')` 或等价机制）以**即时重渲染**
- **FR-007**: 词典条目必须 **zh/en 成对**；缺项回退中文
- **FR-008**: 未迁移页面必须保持中文，**不出现键名/空白外泄**
- **FR-009**: 含变量的文案必须使用参数化替换（安全，不暴露键名或占位符）
- **FR-010**: 本特性**仅改文案**，不得改变既有业务逻辑、数据获取与交互行为
- **FR-011**: 业务数据（课程名/邮件主题/通知标题等）**不得被翻译**
- **FR-012**: 语言偏好沿用既有持久化与 AppStorage 机制（不新增存储）

### Key Entities *(include if feature involves data)*

- **翻译词条**：键（带页面前缀）、中文文案、英文文案
- **导航项**：标签键、页面标识
- **状态文案**：加载/空态/失败/重试/演示提示

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 切换语言后，首批页面在 **1 秒内**完成文案切换（≥ 95% 文案随切换更新）
- **SC-002**: 首批页面在 English 下**残留中文率 = 0**（业务数据除外）
- **SC-003**: 未迁移页面键名/空白外泄**发生次数 = 0**
- **SC-004**: 词典 zh/en **成对率 = 100%**
- **SC-005**: 首批页面功能回归通过（导航、加载、空态、错误可重试、演示模式行为不变）
- **SC-006**: 切换语言并重启后，语言偏好保持（沿用既有持久化）

## Assumptions

- **首批范围**：底部导航 + 首页/学习/课表/校园/AI/登录，及其状态与错误文案
- **不在首批**：校园子页（邮箱/网课/图书馆/研读间/体育/宿舍/财务/资讯/程序）与学习子页详情；其文案留待下一批次
- 数据源与业务逻辑不变；本特性**不新增网络请求**、不改数据模型
- 课表页文案迁移与 `schedule-visual`（块状重构）**协同**：由 `schedule-visual` 使用本特性的词典键
- 词典条目命名遵循既有前缀约定（`settings.*` 已存在）
- 参数化文案以字符串占位安全替换实现（无第三方 i18n 库）
