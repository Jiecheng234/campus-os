# 学习页 & 校园页 ArkTS 实现方案

## 1. 学习页 (LearningPage)

### 布局

```
┌────────────────────────────────────┐
│  SafeTop                           │
│  学习                              │  ← 标题
│  3 门课程 · 2 项作业 · 1 通知 · 0 文件│  ← 统计副标题       [+] 按钮
│                                    │
│  ┌────┬────┬────┬────┐            │
│  │课程3│作业2│通知1│文件0│            │  ← 分段控件 (pill 形状)
│  └────┴────┴────┴────┘            │
│  ──────────────────────────────── │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ 高等数学(1)    李老师  MATH101 │ │  ← 课程卡片
│  ├──────────────────────────────┤ │     点击 → Toast 详情
│  │ 大学物理B(2)   王老师  PHYS201 │ │
│  ├──────────────────────────────┤ │
│  │ 线性代数       张老师  MATH201 │ │
│  └──────────────────────────────┘ │
│                                    │
│  ... (根据选中 tab 切换内容)       │
└────────────────────────────────────┘
```

### 4 个子标签

| Tab | 硬编码数据 | 卡片内容 |
|-----|----------|---------|
| 课程 (3) | 3 门课程 | 课程名 + 教师 + 编号 |
| 作业 (2) | 2 个 DDL | 标题 + 课程 + 截止时间 + 状态标签(即将截止/已逾期) |
| 通知 (1) | 1 条通知 | 标题 + 发布者 + 时间 + NEW 标签 |
| 文件 (0) | 空 | EmptyState "暂无文件" |

### 添加 DDL 弹窗

底部 Sheet（同设置页语言选择器风格）：
- 标题输入 (必填)
- 日期输入 (默认今天)
- 时间输入 (默认 23:59)
- 课程输入 (选填)
- 备注输入 (选填)
- 取消 / 保存 按钮

## 3. 子页面导航

不引入 ArkUI Navigation 完整路由，使用简单的内部状态栈：

```typescript
// CampusPage 内部
@State subScreen: string = ''; // '' = 列表, 'classroom' | 'grades'

build() {
  if (this.subScreen === 'classroom') {
    ClassroomPage({ onBack: () => { this.subScreen = ''; } })
  } else if (this.subScreen === 'grades') {
    GradesPage({ onBack: () => { this.subScreen = ''; } })
  } else {
    // 列表视图
  }
}
```

子页面顶部有返回箭头按钮。
