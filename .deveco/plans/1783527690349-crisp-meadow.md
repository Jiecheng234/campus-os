# CampusOS ArkTS 逐页迁移 MVP 方案

## 目标

在 harmony/ 工程中用 ArkTS/ArkUI 重写核心页面，产出可交互的最小可用示例：

- ✅ 6 标签页底部导航（匹配原 RN 布局）
- ✅ 首页仪表盘（问候 + 简报卡片 + 今日课程 + 快捷操作）
- ✅ 课表页（周网格 + 周切换）
- ✅ 设置页（语言切换 + 关于信息）
- ✅ 编译通过 + 真机运行可交互

## 技术选型

| 维度 | RN 原实现 | ArkTS 替代 |
|------|----------|-----------|
| 导航 | React Navigation v7 (native-stack + bottom-tabs) | `Navigation` + `Tabs` (ArkUI) |
| 状态 | Redux Toolkit (6 slices) | `@State` / `@Provide` / `AppStorage` (MVP 阶段硬编码) |
| 列表 | `FlatList` / `ScrollView` | `List` / `Scroll` |
| 动画 | `FadeIn` (reanimated) | `animateTo` / `transition` |
| 主题色 | `colors.ts` (purple #7C5CFA) | 直接内联色值，后续抽 resource |
| i18n | `useTranslation` hook (zh/en) | 硬编码中文（MVP），后续补 resource string |

## 页面设计

### 1. 底部标签导航 (Tabs)

```
┌────────────────────────────────────┐
│         页面内容区                   │
│                                    │
│                                    │
├────────────────────────────────────┤
│ 首页 │ 学习 │ 课表 │ 校园 │ AI │ 设置 │
│  🏠  │  📚  │  📅  │  🏫  │ 🤖 │  ⚙️  │
└────────────────────────────────────┘
```

- ArkUI `Tabs` 组件，`BarPosition.End`（底部）
- Tab 图标使用 Text emoji 占位（后续替换为 Resource 图标）
- 选中态：`fontColor: '#7C5CFA'`，底部指示条

```
┌────────────────────────────────────┐
│  ←  第18周  2026年7月  →           │  ← 周选择器
│  一    二    三    四    五    六  日 │  ← 星期头
│ ───────────────────────────────── │
│  ┌──────┬──────┬──────┬──────┐   │
│  │ 08:00│      │ 物理 │      │   │  ← 时间网格
│  │      │      │      │      │   │
│  ├──────┼──────┼──────┼──────┤   │
│  │ 10:10│ 高数 │      │ 英语 │   │

│  ├──────┼──────┼──────┼──────┤   │

└────────────────────────────────────┘
```

- 顶部：`Row` 周选择器（左右箭头 + 周次 + 月份）
- 星期头：`Row` 7 列
- 时间网格：`Grid` 组件（8 行 × 7 列）
- 每行高度对应时间段（60min = 60dp）
- 课程块：紫色背景（`rgba(124,92,250,0.15)`），圆角，显示课程名

- 点击"语言"弹出 `ActionSheet` 切换中/英文
- 其他项显示 Toast "功能开发中"

### 5. 占位页面 (Learning / Campus / AI)

每个页面显示居中的图标 + 标题 + "功能开发中" 文字，保持导航框架完整性。

1. `hvigorw assembleHap` 编译通过
2. 真机部署 → 看到底部 6 标签导航
3. 切换标签页无 crash
4. 首页显示问候 + 课程卡片 + 快捷按钮
5. 课表页可切换周次
6. 设置页点击"语言"弹出选择弹窗

## 回滚

MVP 仅在 `harmony/entry/src/main/ets/pages/` 下新增文件 + 修改 `Index.ets`。
不影响 `entryability/` 和 `turbomodules/`。
如需回退，恢复 `Index.ets` 到当前版本即可。
